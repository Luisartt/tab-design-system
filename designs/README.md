# TAB designs: piezas de referencia

Piezas ya generadas con el sistema de diseño de TAB. Son **stills de clips verticales de 1080×1920 (9:16)** y sirven como referencia de composición y estilo (layout, color, tipografía, motivos, logo). Para una publicación de Instagram o LinkedIn se recompone el mismo diseño a **1080×1350 (4:5)**; no se estiran ni se recortan.

Nombre de archivo: `TAB-<elemento>-<variante>-v.png` (`-v` = vertical). Las hojas `tab-hoja-*` y `tab-poster` resumen varias variantes.

| Categoría | Archivo |
|---|---|
| Portada / gancho | `TAB-headline-light-v`, `TAB-headline-navy-v` |
| Caso de éxito | `TAB-case-study-diagonal-v` (más variantes en `tab-hoja-casos`) |
| Testimonio / cita | `TAB-quote-card-testimonio-v` |
| Cifra clave | `TAB-metric-porcentaje-v`, `TAB-stats-trio-gerentes-v` |
| Gráficas | `TAB-bar-chart-barras-v`, `TAB-line-chart-crecimiento-v`, `TAB-donut-reparto-v`, `TAB-progress-bars-metas-v` (`tab-hoja-graficas`) |
| Antes y después / contraste | `TAB-before-after-stratpro-v`, `TAB-comparison-dos-columnas-v` |
| Proceso | `TAB-process-wheel-stratpro-v`, `TAB-arrow-flow-tres-pasos-v`, `TAB-board-table-sesion-v` (`tab-hoja-proceso`) |
| Checklist | `TAB-checklist-cinco-puntos-v` |

El texto de las piezas es de ejemplo ("dato de ejemplo"); sustitúyelo siempre por contenido confirmado. Cualquier pieza con el logo de TAB requiere aprobación escrita de TAB Marketing antes de publicarse.
